# Saint James Orchestra

Audio data collection.

- **Library**: Saint James Orchestra
- **Format**: SF2 SoundFont files (served as-is for SF2 sampler)
- **Files**: 48 SF2 files
- **Source**: open-soundfonts/Saint_James_Orchestra_soundfonts

## Opus previews (r100 mint)

- 48 `SJO_<Name>.opus` previews minted from the sf2 sample data (one representative sample per instrument, closest-to-C4 among parsable note names, first-sample fallback otherwise; BOTH A/B legs consume the same file).
